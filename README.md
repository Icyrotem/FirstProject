# FirstProject - 2D Space Shooter Game

A Unity 2D space shooter game where players control a spaceship that moves horizontally and shoots projectiles to destroy waves of enemies.

## Game Features
- Horizontal player movement with arrow keys
- Shooting mechanics with 'S' key
- Enemy wave spawning system
- Score tracking system
- Ammo management
- Particle effects on enemy destruction

## Technical Details
- Built with Unity 2022.3.62f1
- Uses Universal Render Pipeline (URP)
- Implements Unity's Physics2D system
- Features object pooling for projectiles and enemies

## Controls
- Arrow Keys: Move player left/right
- S Key: Shoot projectiles

## Gameplay
Destroy all enemies in a wave to advance to the next level. Each wave spawns more enemies and provides limited ammo. Score points by destroying enemies.
